# 推箱子编辑器与最优解求解器

一个无需安装、无需联网的 Sokoban 地图编辑器和求解器。打开 `index.html` 即可使用。

## 功能

- 鼠标绘制地图，支持撤销、重做和调整网格大小
- 导入、导出标准地图文本，也可从内置关卡开始
- 用 A* 搜索最少步数解或最少推箱数解
- 搜索采用静态死角和 2×2 冻结死锁剪枝，最多搜索 2000 万个节点
- 查看逐步回放、走法字母串和中文解题过程
- 全部逻辑在本机浏览器运行，不上传地图

## 使用

下载或克隆仓库后，直接用现代浏览器打开 `index.html`。页面没有第三方依赖，也不需要构建步骤。

## 地图字符

| 字符 | 含义 |
| --- | --- |
| `#` | 墙 |
| `-`、空格 | 地板 |
| `.` | 目标点 |
| `$` | 箱子 |
| `@` | 玩家 |
| `*` | 箱子在目标点 |
| `+` | 玩家在目标点 |

## 搜索说明

两种模式都使用 A* 搜索，并返回各自代价下的最优解。大地图或箱子较多的关卡可能需要较长时间和较多内存；达到节点或时间上限时，页面会提示搜索未完成。最少推箱数模式会把空走路径还原为完整走法。
